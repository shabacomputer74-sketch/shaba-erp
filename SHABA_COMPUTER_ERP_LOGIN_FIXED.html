💾 ERP Data Backup & Restore

Online + Offline migration শুরু করার আগে বর্তমান ERP-এর সব Browser Data-এর নিরাপদ Backup রাখা যাবে। এই Backup-এ Company, Product, Customer, Seller, Invoice, Payment, Warranty, Damage/Waste এবং প্রয়োজনীয় Counter Data থাকবে।

⬇️ Backup

বর্তমান ERP-এর সব Local Data একটি JSON ফাইলে সংরক্ষণ করুন।

⬆️ Restore

আগের Backup JSON ফাইল থেকে ERP Data ফিরিয়ে আনুন। Restore করার আগে বর্তমান Data-এর Backup নেওয়া বাধ্যতামূলক।

☁️ Google Drive Backup

Google Drive-এ নিয়মিত ERP Data Backup রাখা যাবে। এটি Cloud Sync-এর database নয়; এটি নিরাপদ Backup/Restore-এর জন্য।

🧹 Clear Test Data / Reset ERP

এই অপশনটি শুধু Admin ব্যবহার করতে পারবেন। এটি test/business data পরিষ্কার করবে, কিন্তু Company Profile, User/Permission, Audit Log এবং Online/Offline configuration রাখবে।

⚠️ সতর্কতা: এখন প্রতিটি Business Data আলাদা আলাদাভাবে Reset করা যাবে। যে অপশনে Reset করবেন, শুধু সেই অপশনের Data পরিষ্কার হবে। অন্য Module-এর Data থাকবে। Reset করার আগে Safety Backup Download হবে।
